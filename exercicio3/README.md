# Sistema Amigo Secreto - POO 2026.1

Sistema de gerenciamento de brincadeira de Amigo Secreto desenvolvido em Java como parte do Exercício 3 da disciplina de Programação Orientada a Objetos.

## Classes

* **Amigo** - Representa um participante da brincadeira
* **Mensagem** - Classe abstrata que representa uma mensagem
* **MensagemParaTodos** - Mensagem enviada para todos os participantes
* **MensagemParaAlguem** - Mensagem enviada para um participante específico
* **SistemaAmigo** - Gerencia amigos e mensagens usando List
* **SistemaAmigoMap** - Gerencia amigos e mensagens usando HashMap

## Funcionalidades

* Cadastrar amigo
* Pesquisar amigo
* Enviar mensagem para todos
* Enviar mensagem para alguém
* Pesquisar mensagens anônimas
* Configurar amigo secreto
* Pesquisar amigo secreto
